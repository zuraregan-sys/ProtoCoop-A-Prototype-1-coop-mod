PROTOTYPE COOP - LEEME
======================

QUE ES
Coop online para Prototype (2009). El anfitrion abre ONLINE y los demas
jugadores se unen desde el mismo menu. El mod sincroniza el avatar remoto, su
pose, poderes, dano/destruccion, agarres, particulas y decals.

REQUISITOS
- Prototype (2009) de Steam, 32 bits, con la carpeta del juego.
- PrototypeFix 1.8.0 de emoose, instalado aparte desde Nexus y con
  PreferLooseFiles = true. Este ZIP no incluye PrototypeFix.
- Steam abierto y con sesion iniciada para descargar la API y jugar.
- El puerto TCP 27015 debe estar libre al arrancar. Prototype se conecta a ese
  puerto durante el inicio; si otro programa lo ocupa (por ejemplo Apple Mobile
  Device Service / iTunes), el juego se queda colgado antes de abrir la
  ventana. El lanzador lo detecta y ofrece detener ese servicio. Este paquete
  no modifica ni sustituye prototypef.exe.

INSTALACION
1. Extrae TODO el ZIP en una carpeta normal (no ejecutes el .exe desde dentro
   del ZIP).
2. Ejecuta PrototypeCoopLauncher.exe.
3. Selecciona la carpeta que contiene prototypef.exe. En Steam suele ser
   steamapps\common\Prototype.
4. Instala PrototypeFix 1.8.0 de emoose desde Nexus en la carpeta del juego
   y activa PreferLooseFiles = true. El lanzador solo lo detecta; no lo
   incluye en el ZIP.
5. Pulsa Instalar / Actualizar. El lanzador:
   - copia el mod,
   - busca una steam_api.dll compatible en tu biblioteca de Steam o descarga
     la version publica de Steamworks.NET y comprueba su SHA-256,
   - genera art\hud\protomainmenu.gfx y art\hud\protodevmenu.gfx desde tu
     propio art.rcf (no se descargan assets del juego).
6. Inicia el juego desde el lanzador. Su boton Iniciar comprueba antes el
   puerto TCP 27015; si lo ocupa otro programa (por ejemplo Apple Mobile Device
   Service / iTunes), ofrece detenerlo. Arrancar directamente desde Steam se
   salta esa comprobacion y el juego puede quedarse colgado.

Nota: las comprobaciones automaticas de actualizaciones necesitan v0.1.7 o
superior. Si vienes de una version anterior, actualiza una vez a mano.

ORDEN DE CARGA / PROTOTYPEFIX
PrototypeFix instala su propio binkw32.dll (y binkw32Hooked.dll). Este ZIP no
toca ni sustituye binkw32.dll, binkw32Hooked.dll ni prototypeenginef.dll.
El juego carga xinput1_3.dll; ese proxy carga prototype_coop.asi y solo carga
prototype_fix.asi si PrototypeFix no lo ha cargado ya. Comprueba la lista de
modulos, asi que cada ASI se inicializa una vez. PreferLooseFiles = true en
prototype_fix.ini hace que el juego use los menus generados en art\hud.

No se incluye ningun parche del ejecutable. El juego se arranca por Steam
como cualquier otro juego.

VERIFICAR ARCHIVOS
En Instalar, pulsa Verificar archivos despues de un aviso del antivirus, una
instalacion fallida o una actualizacion parcial. Comprueba la version del
juego, los hashes del mod, el proxy, los menus y la API de Steam, PrototypeFix
con PreferLooseFiles, y coop.ini. Repara solo lo que falta o esta danado.
PrototypeFix es de terceros: no se instala ni se reemplaza. Tus partidas,
coop.ini, registros y PrototypeFix se conservan.

CARPETAS Y PARTIDAS
El lanzador recuerda la carpeta del juego. En Jugar hay botones para abrir la
carpeta del juego, las partidas coop en Documentos\Prototype Coop y los
registros. Respaldar partidas copia profile.bin y slot-*.bin a la carpeta de
datos del lanzador; el primer install tambien crea una copia automatica. Solo
se copian las partidas y se conservan las cinco copias mas recientes.

MODO PORTABLE
En Ajustes, Modo portable guarda actualizaciones, copias para revertir,
informes y copias de partidas en data junto al lanzador. Las partidas del juego
siguen en Documentos\Prototype Coop. Mueve la carpeta completa del lanzador.

DESINSTALAR
Cierra el juego, abre Instalar y pulsa Desinstalar. El lanzador quita
prototype_coop.asi, coop_steam_api.dll y el proxy XInput, restaura los menus
originales desde las copias de seguridad o elimina los menus sueltos para que
el juego use art.rcf, y devuelve el steam_appid.txt si lo habia quitado. No
toca las partidas, coop.ini, los registros ni PrototypeFix. Despues puedes
volver a instalar el mod con el mismo lanzador.

VERSIONES
El lanzador y el mod tienen versiones separadas. El pie del lanzador muestra
las dos y la pestana Novedades contiene el historial de todos los cambios.

COMPROBACION DE VERSION
Al entrar el segundo jugador, los dos mods intercambian su version y el
protocolo de red. En la esquina inferior izquierda del lobby aparece una
tarjeta nativa:
- EN SINCRONIA: misma version del mod.
- VERSION DISTINTA: mismo protocolo, distinta version. Actualiza el mod en los
  dos PCs.
- INCOMPATIBLE: protocolo distinto; el anfitrion no puede iniciar la partida
  hasta actualizar los dos mods.
- CONECTANDO...: esperando la respuesta del otro jugador.

version_gate=block (por defecto en coop.ini) impide iniciar con versiones
distintas; version_gate=warn lo permite mostrando el aviso (usa el mismo ajuste
en los dos PCs). Un protocolo distinto siempre bloquea. coop_version.txt guarda
las versiones y el estado, y se incluye en el informe de Estado y en el ZIP de
fallos.

OVERLAY Y CHAT
Ctrl+F12 muestra u oculta la tarjeta de version/protocolo/ping durante la
partida. El ping se mide cada segundo: verde por debajo de 80 ms, ambar por
debajo de 150 ms y rojo por encima.

El chat esta disponible mientras los dos jugadores estan conectados (lobby o
partida):
- Y abre el chat arriba a la derecha. Enter envia y el chat sigue abierto; Esc
  cierra (el aviso ESC PARA CERRAR aparece resaltado abajo).
- AvPag/RePag o las flechas recorren el historial.
- Si llega un mensaje con el chat cerrado, aparece un aviso de cinco segundos
  con "PULSA Y EN TU TECLADO PARA CHATEAR".
- Los mensajes solo estan en memoria. No se guardan en disco y se borran al
  perder la conexion o al ser expulsado; sobreviven a las cargas de nivel.

chat=1 en coop.ini activa el chat; version_overlay=1 activa la tarjeta.

ACTUALIZACIONES
La pestana Novedades tiene Buscar actualizaciones y un selector Estable/Beta.
Estable ignora los prereleases de GitHub; Beta los incluye. El lanzador tambien
comprueba una vez al arrancar. Si hay una version nueva muestra Ver cambios,
Descargar paquete, Omitir esta version o Cerrar. Omitir oculta esa version en
los proximos arranques; Buscar actualizaciones la vuelve a mostrar.

Descargar paquete guarda antes una copia de la version actual, baja el ZIP
oficial, comprueba su SHA-256 y lo extrae en la carpeta de datos del lanzador
(Documentos\Prototype Coop\updates o data\updates en modo portable), dentro de
una carpeta visible con instrucciones. Despues cierra el lanzador,
copia esos archivos sobre la carpeta del lanzador y abre el nuevo
PrototypeCoopLauncher.exe. Si el mod tambien cambio, pulsa Instalar.

REVERTIR
Las copias anteriores se guardan en la carpeta de datos del lanzador
(Documentos\Prototype Coop\rollbacks o data\rollbacks en modo portable). El
boton Revertir de Novedades las lista. Cierra el lanzador, copia la carpeta
elegida sobre la carpeta del lanzador, abre el PrototypeCoopLauncher.exe antiguo
y pulsa Instalar. Es manual: no se reemplaza solo ni ejecuta nada oculto. Tus
partidas, coop.ini, registros y PrototypeFix no se tocan.

La comprobacion automatica necesita v0.1.7 o superior. Las versiones anteriores
deben actualizarse una vez a mano.

COMENTARIOS
La pestana Comentarios abre un cuadro de texto para escribir al desarrollador.
Solo se envian el mensaje y las versiones del lanzador y del mod; no se envia
SteamID, nombre, rutas ni datos del equipo. El mensaje pasa por Cloudflare, que
recibe tu IP y guarda solo un hash unos 10 minutos para limitar spam, y llega a
un canal privado de Discord, donde queda hasta que el desarrollador lo borre.
No escribas datos personales: no envies contrasenas, direcciones ni informacion
sensible.

PRIVACIDAD Y RED
El lanzador no tiene analitica ni telemetria y no sube registros por su cuenta.
Al arrancar consulta GitHub para comprobar si hay versiones nuevas; al instalar
descarga Steamworks.NET desde GitHub. GitHub ve tu IP. La pestana Comentarios
solo contacta con Cloudflare y Discord cuando pulsas Enviar. Steam gestiona el
juego, el lobby y el contador de jugadores. Los informes de fallos se guardan en
la carpeta de datos del lanzador (Documentos\Prototype Coop\crash-reports o
data\crash-reports) y solo se suben si tu adjuntas el ZIP a un issue.

El chat solo existe en memoria y viaja al otro jugador por el transporte coop.
Mientras el chat esta abierto usa un hook de teclado local para capturar lo que
escribes; no se registra ni se envia a ningun otro sitio. Con el chat cerrado o
el juego sin foco, las teclas pasan normalmente.

COMO JUGAR
1. Los dos jugadores instalan el mod con el lanzador y abren el juego.
2. El anfitrion: menu principal -> ONLINE. El mod crea una sala PUBLICA.
   El menu del lobby sigue el idioma del juego.
3. Para unirse: el otro jugador abre ONLINE y pulsa BUSCAR. La lista muestra
   el nombre del anfitrion y el ping; elegir una fila entra en esa sala.
4. Para invitar a un amigo: INVITAR abre la lista de amigos de Steam. El amigo
   debe tener el juego abierto y haber abierto ONLINE.
5. El anfitrion pulsa JUGAR; sus partidas coop se envian al invitado y los dos
   abren la pantalla de carga. Cargad la misma partida.

AL UNIRSE
Al elegir un anfitrion, el lobby muestra UNIENDOSE. Si entra, muestra UNIDO
con el nombre del anfitrion; si falla, muestra NO SE PUDO UNIR y puedes
reintentar.

INVITAR A UN AMIGO
Al invitar, la fila de espera del anfitrion muestra INVITADO <nombre>, YA
INVITADO, YA EN LA SALA o SALA LLENA. La lista de amigos marca la fila con
[INVITADO]. Si el invitado rechaza, no se le vuelve a preguntar hasta que el
anfitrion lo invite de nuevo.

EXPULSAR A UN JUGADOR
El anfitrion puede seleccionar el nombre del invitado y pulsar A. La fila
muestra [EXPULSAR]. El invitado recibe el aviso y sale del lobby; Steam no
ofrece expulsion forzada en esta API, asi que un cliente modificado podria
ignorarlo.

IDIOMAS
El lobby y el chat siguen el idioma del juego: espanol, ingles, frances e
italiano, los cuatro que ofrece la version de Steam. Cualquier otro codigo usa
ingles.
El lanzador tiene un selector en Ajustes con espanol, ingles, frances, italiano,
aleman, portugues y neerlandes. El aviso de actualizacion, Novedades, Comentarios
y Revertir usan el mismo idioma.

PROBLEMAS
- Si el lanzador no encuentra una steam_api.dll compatible, comprueba que
  Steam este instalado y con al menos un juego moderno, o que tengas conexion
  para descargar el release publico de Steamworks.NET.
- Si ONLINE no aparece, comprueba que PrototypeFix este instalado y que
  prototype_fix.ini tenga PreferLooseFiles = true.
- Si el juego se abre desde Steam pero el mod no carga, revisa que
  xinput1_3.dll y prototype_coop.asi esten en la carpeta del juego.

ENGLISH
Install PrototypeFix 1.8.0 by emoose separately from Nexus and enable
PreferLooseFiles = true. Then run PrototypeCoopLauncher.exe, select the folder
containing prototypef.exe, press Install, and launch the game. The launcher
installs the mod, obtains a compatible Steam API DLL from your Steam library or
the public Steamworks.NET release, and rebuilds the ONLINE and lobby movies
from your own art.rcf. PrototypeFix is not included in this ZIP. PrototypeFix
installs its own binkw32.dll/binkw32Hooked.dll; this package does not touch or
replace binkw32.dll, binkw32Hooked.dll or prototypeenginef.dll. The game loads
xinput1_3.dll, which loads prototype_coop.asi and only loads prototype_fix.asi
if PrototypeFix's loader has not already done so; each ASI is initialised once.
No game assets, Steam DLL or executable patch is included. TCP port 27015 must be free when
the game starts; if another program (commonly Apple Mobile Device Service)
listens there, Prototype hangs before its window. The launcher detects this and
offers to stop that service. This package does not modify or replace
prototypef.exe.

Automatic update checks require v0.1.7 or newer. If you come from an older
build, update manually once.

VERIFY FILES
On Install, press Verify files after an antivirus warning, a failed install or
a partial update. It checks the game version, mod/proxy/menu and Steam API
hashes, PrototypeFix with PreferLooseFiles, and coop.ini. It repairs only what
is missing or damaged. PrototypeFix is third-party and is never installed or
replaced. Saves, coop.ini, logs and PrototypeFix are kept.

FOLDERS AND SAVES
The launcher remembers the selected game folder. The Play tab has buttons to
open the game folder, the co-op saves in Documents\Prototype Coop, and the game
logs. Back up saves copies profile.bin and slot-*.bin into the launcher data
folder; the first install also creates a backup automatically. Saves are only
copied and the newest five backups are kept.

PORTABLE MODE
In Settings, Portable mode stores updates, rollback copies, reports and save
backups in data next to the launcher. Game saves stay in
Documents\Prototype Coop. Move the whole launcher folder together.

UNINSTALL
Close the game, open Install and press Uninstall. The launcher removes
prototype_coop.asi, coop_steam_api.dll and the XInput proxy, restores the
original menus from the install backups (or removes the loose movies so the
game uses art.rcf), and restores a backed-up steam_appid.txt if the installer
removed one. Saves, coop.ini, logs and PrototypeFix are kept. You can reinstall
the mod afterwards with the same launcher.

VERSIONS
The launcher and the mod are versioned separately. The launcher footer shows
both versions, and the Changelog tab contains the complete update history.

VERSION CHECK
When the second player joins, both mods exchange their mod version and network
protocol. A native card appears in the bottom-left of the lobby:
- IN SYNC: same mod version.
- VERSION MISMATCH: same protocol, different mod version. Update the mod on
  both PCs.
- INCOMPATIBLE: different protocol; the host cannot start until both mods are
  updated.
- LINKING...: waiting for the other player's answer.

version_gate=block (the default in coop.ini) refuses to start with different
versions; version_gate=warn allows it with the warning on screen. A different
protocol always blocks. coop_version.txt keeps the versions and state, and the
Status report and crash ZIP include it.

OVERLAY AND CHAT
Ctrl+F12 shows or hides the version/protocol/ping card during a session. The
ping is measured once a second: green below 80 ms, amber below 150 ms, red
above.

Chat is available while both players are connected (lobby or game):
- Y opens the chat at the top-right. Enter sends. Esc closes.
- PageUp/PageDown or the arrow keys scroll through the history.
- A message received while the chat is closed shows a five-second bubble with
  "PRESS Y ON YOUR KEYBOARD TO CHAT".
- Messages are memory-only. Nothing is written to disk and they are cleared
  when the connection ends or you are kicked; level loads keep them.

chat=1 in coop.ini enables chat; version_overlay=1 enables the card.

UPDATES
The Changelog tab has Check for updates and a Stable/Beta selector. Stable
ignores GitHub prereleases; Beta includes them. The launcher also checks once
on startup. If something is newer, it shows View changes, Download package,
Skip this version, or Close. Skip hides that release on future startups; Check
for updates still shows it.

Download package saves a copy of the current version first, then downloads the
official ZIP, verifies its SHA-256 and extracts it into the launcher data folder
(Documents\Prototype Coop\updates, or data\updates in portable mode), in a
visible folder with instructions. Then close the launcher, copy those files
over the launcher folder and open the new PrototypeCoopLauncher.exe. If the mod
changed too, press Install.

ROLLBACK
Previous copies are kept in the launcher data folder
(Documents\Prototype Coop\rollbacks, or data\rollbacks in portable mode). The Rollback
button on the Changelog tab lists them. Close the launcher, copy the chosen
folder over the launcher folder, open the old PrototypeCoopLauncher.exe and
press Install. This is manual: nothing replaces itself or runs hidden. Your
saves, coop.ini, logs and PrototypeFix are not touched.

Automatic update checks require v0.1.7 or newer. Older versions must update
manually once.

FEEDBACK
The Feedback tab opens a text box for messaging the developer. Only the message
and the launcher/mod versions are sent; no SteamID, username, paths or hardware
data. The message goes through Cloudflare, which receives your IP and keeps
only a hash for about 10 minutes to rate-limit spam, then to a private Discord
channel, where it stays until the developer deletes it. Feedback is not
end-to-end encrypted; do not send passwords, addresses or other sensitive
information.

PRIVACY AND NETWORK
The launcher has no analytics or telemetry and does not upload logs by itself.
On startup it asks GitHub for release metadata; during install it downloads
Steamworks.NET from GitHub. GitHub sees your IP. The Feedback tab contacts
Cloudflare and Discord only when you press Send. Steam handles the game, lobby
and player count. Crash reports are stored locally under Documents and are
uploaded only if you attach the ZIP to a GitHub issue yourself.

Chat is memory-only and travels only to the other player through the co-op
transport. While open, the chat uses a local keyboard hook to capture what you
type; keys are not logged or sent anywhere else. With the chat closed or the
game unfocused, keys pass through normally.

JOINING AND KICKING
After choosing a host the lobby shows JOINING; success shows JOINED with the
host name, failure shows JOIN FAILED. The host can select the guest's [KICK]
row and press A; the guest is asked to leave and sees KICKED. Steam has no
forced lobby kick in this API, so a modified client could ignore it.

INVITING A FRIEND
After inviting, the host's waiting row shows INVITED <name>, ALREADY INVITED,
ALREADY IN LOBBY or LOBBY FULL. The friend list marks the row [INVITED]. A
declined invitation is not offered again until the host invites that friend
again.

LANGUAGES
The lobby follows the game's language: English, Spanish, French and Italian,
plus German, Portuguese and Dutch when the game uses them.
The launcher has a language selector in Settings with English, Spanish, French,
Italian, German, Portuguese and Dutch. The update popup, Changelog, Feedback and
Rollback tabs use the same language.
